# المنصة الإسلامية — المستودع

> **حالة المشروع:** أساس تقني قيد البناء + وثائق تخطيط معتمدة.
> **الأهم:** وجود ملف أو ميزة في هذا المستودع **لا يعني أنها جاهزة للمستخدم**. حالة كل متطلب مكتوبة صراحة في `docs/01-prd.md`.

---

## القرارات المعتمدة (2026-10-26)

| القرار | القيمة |
| --- | --- |
| اللغات | العربية (RTL) والإنجليزية (LTR) من البداية |
| نطاق الإطلاق | الطبقة الأساسية فقط (القرآن، العبادات، المكتبة، الإدارة) |
| الصوتيات | مصادر مرخصة أولًا — لا استيراد قبل إثبات الإذن |
| YouTube / Creator Studio | **مرحلة تحقق** — لا وعود قبل POC وقياس فعلي |
| المراجعة الشرعية | لجنة داخلية (2–3 أعضاء) + إحالة خارجية للخلاف |
| التقنية | Next.js (TypeScript) + PostgreSQL مع RLS |

---

## خريطة المستودع

```
docs/
  01-prd.md               وثيقة المتطلبات (صفحات، رحلات، معايير قبول)
  02-poc-audio.md         خطة إثبات جدوى الصوتيات
  03-poc-youtube.md       خطة إثبات جدوى تكامل YouTube
  04-content-sources.md   المصادر وحقوق المعالجة (نتيجة تحقق موثّقة)
  05-shariah-review.md    لجنة المراجعة الشرعية وسير العمل
  06-roadmap.md           خارطة الطريق وسجل المخاطر
  07-data-model.md        نموذج البيانات وسياسات RLS
db/migrations/            ترحيلات قاعدة البيانات (مسودة مراجَعة)
src/
  app/[locale]/           الصفحات (ar/en)
  i18n/                   القواميس وإعداد اللغة
  components/ui/          مكونات نظام التصميم المشتركة
  lib/                    قاعدة البيانات، التحقق، التسجيل
scripts/                  أدوات تشغيلية (ترحيل القاعدة)
```

## التشغيل

### المتطلبات
- Node.js 20.10+ (مُختبَر على v26)
- Docker (لتشغيل PostgreSQL محليًا)

### الخطوات

```bash
npm install
cp .env.example .env          # ثم عدّل القيم
docker compose up -d          # تشغيل PostgreSQL
npm run db:migrate            # تطبيق الترحيلات
npm run dev                   # http://localhost:3000
```

### الأوامر

| الأمر | الوظيفة |
| --- | --- |
| `npm run dev` | خادم التطوير |
| `npm run build` | بناء الإنتاج |
| `npm run lint` | فحص الأسلوب |
| `npm run typecheck` | فحص الأنواع |
| `npm test` | الاختبارات (تشمل اكتمال القاموس عربي/إنجليزي) |
| `npm run db:migrate` | تطبيق ترحيلات قاعدة البيانات |

## الفحوصات الإلزامية قبل الدمج

- [ ] `npm run typecheck && npm test && npm run lint` خضراء.
- [ ] أي نص جديد موجود في القاموس بالعربية والإنجليزية.
- [ ] أي محتوى جديد له صف في `content_sources` بحالة موثّقة.
- [ ] تحديث حالة المتطلب في `docs/01-prd.md`.
- [ ] لا مفاتيح أو رموز وصول في حزمة المتصفح أو السجلات.

## ما هو خارج النطاق حاليًا

- أي تكامل YouTube كامل أو نشر فعلي.
- استيراد ملفات صوتية محفوظة بحقوقها.
- إعلان أي ميزة من `قيد التحقق` كأنها جاهزة.
