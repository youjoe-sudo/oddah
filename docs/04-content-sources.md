> **المبدأ المعتمد:** وجود مصدر أو API أو رابط لا يعني وجود إذن بالاستخدام. كل مصدر هنا له حالة صريحة: `موثّق` أو `يحتاج تحقق` أو `مرفوض مؤقتًا`.

### 4.2 ملفات الإدخال — **هذا هو العقد الحقيقي**

> رخصة الأداة لا تمنح أي حق في الملف الذي نعالجه. الفصل الصوتي لملف محفوظ بحقوقه لا يغيّر وضعه القانوني.

| مصدر ملفات الاختبار | الحالة | الاستخدام المسموح في POC |
| --- | --- | --- |
| تسجيلات نصنعها بأنفسنا (فريق العمل) | ✅ مسموح | ملفات اختبار أساسية |
| موسيقى بترخيص CC-BY/CC0 من مصادر موثّقة | ✅ مسموح مع الإسناد | توسيع مجموعة الاختبار بعد فحص رخصة كل ملف |
| أغاني من منصات استماع/يوتيوب عبر تنزيل | ❌ **ممنوع** | لا يُستخدم مطلقًا في POC ولا في المنتج |
| ملفات "مرسلة من مستخدم" | ⚠️ شرط | تفعيلها لاحقًا بشروط استخدام تمنع المحتوى المحمي + بلاغ + إزالة فورية |

**قائمة تحقق إلزامية لكل ملف قبل المعالجة:**
1. مصدر الملف ومالك الحقوق.
2. الرخصة النصية موثّقة (وثيقة/رابط دائم لا يتغير).
3. هل الرخصة تسمح **بالمعالجة الآلية** (الاستيراد، الفصل، التخزين المؤقت)؟
4. مدة الاحتفاظ بالملف الأصلي والنتائج والحذف التلقائي بعد المعالجة.
5. هل يسمح بعرض الناتج تجاريًا (الباقات المدفوعة)؟

## 5. تكامل YouTube

| البند | ما تم التحقق منه | الحالة |
| --- | --- | --- |
| الحصص الافتراضية | 10,000 وحدة/يوم لكل مشروع؛ `search.list` و`videos.insert` لهما دُلو مستقل (100 استدعاء/يوم بحسب Google Quota Calculator) | ⚠️ متعارض بين مراجع قديمة (1,600 وحدة للاختيار) — **نقيس فعليًا في POC** |
| تصنيف النطاقات | كل نطاقات YouTube تُصنَّف sensitive (بما فيها للقراءة فقط) | ✅ موثّق |
| التطبيق غير المُوثَّق | حتى **100 مستخدم اختباري** يمكنهم المنح؛ خارجهم تحذير "غير موثّق" | ✅ موثّق |
| مدة المراجعة | sensitive: 3–5 أيام عمل؛ restricted: 4–6 أسابيع + تقييم أمني سنوي عند تخزين بيانات على خادم | ✅ موثّق (تقديرات Google) |
| رموز OAuth | تُخزَّن مشفّرة في مخزن أسرار خادمي فقط؛ **لا تمر عبر المتصفح أبدًا** | ✅ قرار معماري |
| حد رموز التحديث | 100 refresh token لكل عميل ومعرف Google؛ رموز التطوير قد تنتهي خلال 7 أيام حسب حالة التطبيق | ⚠️ يحتاج تحقق مباشر وقت التنفيذ |

**القرار:** كل ما يخص YouTube يبقى في **مرحلة التحقق** حتى نُنفّذ POC على قناة تجريبية يملكها الفريق ونقيس الأرقام بأنفسنا.
