# المراجعة الشرعية — اللجنة الداخلية وسير العمل

> **القرار المعتمد (2026-10-26):** لجنة شرعية داخلية (2–3 أعضاء) + مسار إحالة خارجي للمسائل الخلافية، مع سجل مراجعة لكل محتوى.
> **الهدف:** دقة المحتوى الإسلامي دون تعطيل سرعة النشر، وبلا تقديم استنتاجات ذكاء اصطناعي كنصوص شرعية أصلية.

---

## 1. أعضاء اللجنة والاختصاص

| العنصر | التعريف |
| --- | --- |
| العضو الأول | مسؤول عن النصوص والفتاوى الصريحة |
| العضو الثاني | مسؤول عن المحتوى التعليمي والدروس |
| العضو الثالث (اختياري) | مراجع خارجي متاح عند الحاجة |
| المسؤول الفني | يوثّق القرارات ويصعّد للمراجعة، ولا يصدر أحكامًا |

**الإحالة الخارجية:** مسألة خلافية أو فتوى حساسة → تُعرض على جهة إفتاء معتمدة، ولا تُنشر قبل الرد.

---

## 2. فئات المحتوى ومستوى المراجعة

| الفئة | أمثلة | مستوى المراجعة |
| --- | --- | --- |
| **A — نصوص أصلية** | القرآن، الحديث (مع درجته)، نصوص مصنَّفة | **إلزامية قبل النشر** — مصدر + إسناد + درجة |
| **B — شروح وفتاوى** | تفسير، فقه، إجابة سؤال | مراجعة فردية + توثيق المرجع |
| **C — تعليمي عام** | دروس لغة، أخلاق، سيرة | مراجعة عيّنة دورية (10–20%) |
| **D — محتوى مستخدم** | مشاركات المجتمع | بلاغ + مراجعة عند البلاغ + فلاتر |

---

## 3. سير العمل

```
إنشاء/تعديل محتوى → فحص آلي (المصدر، الإسناد، الحالة)
        ↓
   فئة A/B: مراجعة لجنة ──→ قرار: [اعتماد | تعديل | رفض | إحالة]
        ↓                                          ↓
   فئة C: عيّنة دورية                     مسألة خلافية → جهة إفتاء خارجية
        ↓                                          ↓
   نشر + تسجيل في content_reviews و audit_logs ←──┘
```

| الحالة | المعنى |
| --- | --- |
| `draft` | لم يُرسل للمراجعة |
| `in_review` | لدى المراجع |
| `approved` | معتمد للنشر (اسم المراجع + الوقت) |
| `changes_requested` | مُعاد مع ملاحظات |
| `escalated` | مُحال خارجيًا — **لا يُنشر** |
| `rejected` | مرفوض |

---

## 4. قواعد التعامل مع الاختلاف

1. **الروايات القرآنية:** تُعرض كما وردت من مصدرها الموثّق، دون "توحيد" أو تعديل للنص (Tanzil: التعديل ممنوع).
2. **الفقه المتباعد:** يُعرض بجانب المحتوى تنبيه صريح بوجود خلاف، مع ذكر المذهب/المرجع عند النشر — لا تحييد صامت ولا حسم من الخادم.
3. **الحديث:** لا يُعرض حديث إلا بدرجة توثيقه ومرجعه؛ الحديث الضعيف لا يُنقل كحديث نبوى.
4. **الإجابة الآلية (AI-01):** كل إجابة تحمل مراجع قابلة للتحقق؛ ما لا مرجع له يُعلَّم "غير مسنود"؛ **لا يُعرض أي استنتاج آلي كنص شرعي أصلي**.

---

## 5. سجل المراجعة (إلزامي)

كل قرار يُسجَّل في `content_reviews`:

| الحقل | مثال |
| --- | --- |
| `content_item_id` | القطعة |
| `reviewer_id` | عضو اللجنة |
| `decision` | `approved` |
| `notes` | ملاحظة قرار |
| `citations` | المرجع المعتمد (رابط/كتاب/صفحة) |
| `created_at` | وقت القرار |

وينعكس في `audit_logs` للتدقيق. **لا نشر لفئة A/B دون صف مراجعة مكتمل.**

---

## 6. معايير القبول للعملية

- [ ] سياسة المراجعة موثّقة ومتاحة لأعضاء اللجنة.
- [ ] كل محتوى فئة A منشور له قرار مراجعة باسم عضو ووقت.
- [ ] المسار الخارجي (الإحالة) مُختبَر بمحتوى تجريبي واحد على الأقل.
- [ ] تنبيه الخلاف يظهر صحيحًا في العرض العربي والإنجليزي.
- [ ] اختبار يرفض نشر فئة A بحالة `in_review`.
